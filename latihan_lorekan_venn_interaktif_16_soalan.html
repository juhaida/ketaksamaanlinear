Soalan 1 / 16

Rajah Venn – klik kawasan untuk melorek0 kawasan dipilih

Tekan nombor label atau mana-mana bahagian kawasan untuk lorek / padam lorekan. Biru = lorekan murid.

📘 Panduan menjawab – teknik label
Langkah 1: Kenal pasti kawasan setiap set mengikut nombor label pada rajah.
Langkah 2: Simbol ∪ bermaksud kesatuan (gabung semua kawasan); ∩ bermaksud persilangan (kawasan sepunya).
Langkah 3: Tanda ′ bermaksud pelengkap dalam set semesta ξ. Lorek kawasan yang tidak termasuk dalam set tersebut.
Langkah 4: Selesaikan kurungan dahulu, kemudian tentukan nombor label yang perlu dilorek.
Langkah 5: Tekan kawasan pada rajah dan pilih Semak jawapan.

Set semesta dalam latihan ini ialah ξ = X ∪ Y ∪ Z. Bahagian luar semua bentuk tidak dikira sebagai kawasan semesta.

🔎 Panduan untuk soalan semasa (tanpa jawapan)

Latihan kendiri Matematik SPM • Setiap petak warna ialah kawasan mengikut label, bukan nombor unsur set.
