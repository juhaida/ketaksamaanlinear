📘 Set Tingkatan 1 KSSM

10 soalan objektif + 5 soalan subjektif

Topik: elemen, bilangan elemen, subset, pelengkap dan set semesta

Markah direkod dalam Google Sheet yang sama dengan nama set SET - TINGKATAN 1 KSSM.
Bahagian A — Objektif (10 markah)

1. Diberi A = {2, 4, 6, 8}. Pernyataan yang manakah benar?

2. Diberi B = {a, e, i, o, u}. Apakah n(B)?

3. Diberi C = {1, 2, 3}. Yang manakah merupakan subset C?

4. Berdasarkan rajah, apakah pelengkap bagi set P, iaitu P′?

5. Berdasarkan rajah, apakah set A ∩ B?

6. Berdasarkan rajah berikut, apakah nilai n(Q)?

7. Diberi ξ = {1,2,3,4,5,6} dan A = {2,4,6}. Apakah A′?

8. Jika satu set mempunyai 3 elemen, berapakah bilangan subset bagi set itu?

9. Berdasarkan rajah, hubungan yang betul bagi set R dan S ialah...

10. Antara berikut, yang manakah sesuai menjadi set semesta bagi A = {2,4,6}?

Bahagian B — Subjektif (10 markah)

11. A ialah set nombor genap positif kurang daripada 10. Senaraikan elemen A.

Tulis jawapan dalam bentuk set, contoh: {1,2,3}

12. Diberi B = {2,4,6,8,10,12}. Nyatakan bilangan elemen B.

13. Diberi C = {a,b,c}. Senaraikan semua subset C yang mempunyai tepat 2 elemen.

Contoh: {a,b}, {a,c}, {b,c}

14. Diberi ξ = {1,2,3,4,5,6,7,8} dan D = {2,4,6,8}. Nyatakan D′.

15. Diberi E = {1,3,5} dan F = {2,4,6}. Nyatakan satu set semesta yang sesuai yang mengandungi semua elemen E dan F.
